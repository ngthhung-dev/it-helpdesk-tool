# Tài khoản đăng nhập IT Helpdesk Tool

Nhánh này chỉ chứa `accounts.json` — danh sách tài khoản được phép mở app (bản đăng nhập online).
Mật khẩu **không** được lưu, chỉ lưu mã băm PBKDF2-SHA256 (210.000 vòng, có muối).

Quản lý bằng app: đăng nhập tài khoản quản trị → Giới thiệu → **Quản lý tài khoản**.
